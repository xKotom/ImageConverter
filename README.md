# Универсальный конвертер изображений

Курсовая работа: настольное приложение для пакетной конвертации фотографий (C++20, Qt 6 Widgets, CMake).
Реализованы этапы 0–5 плана из ТЗ: окно, drag & drop, определение формата по содержимому,
JPEG/PNG/BMP/WEBP/**GIF/TIFF/HEIC/AVIF**, настройки, очередь с отменой и повтором, обработка ошибок, предпросмотр,
**анимация, многостраничные файлы и перенос метаданных**.
Видео (этап 6) и интеграция с Проводником Windows (этапы 8–10) — последующие этапы, в код не входят.

## Возможности

- Добавление файлов, папок (рекурсивно) и drag & drop; повторы отбрасываются; импорт идёт в фоне.
- Формат определяется **по содержимому** (сигнатуры + проверка декодером); расширение — только подсказка.
  `photo.jpg`, внутри которого PNG, распознаётся как PNG с предупреждением.
- Доступные форматы строит `CodecRegistry` из реально загруженных плагинов Qt: нет encoder — формат не предлагается.
- Предупреждения **до** запуска: потеря прозрачности (заливка выбранным фоном), сжатие с потерями,
  потеря ICC/метаданных, анимация (только первый кадр или отказ), несовпадение расширения.
- Очередь: ожидание → выполнение → успех / ошибка / отмена / пропуск, прогресс по каждому файлу,
  отмена, явный повтор, ограниченная параллельность (по умолчанию 2 потока). Ошибка одного файла не останавливает пакет.
- Безопасная запись: временный файл с непредсказуемым именем в папке назначения → проверка
  (размер, повторное чтение, размеры) → переименование. При ошибке/отмене остаток удаляется. Исходник не изменяется
  и никогда не выбирается как путь результата. Конфликт имён: суффикс `(1)`, замена (с подтверждением) или пропуск.
- Предпросмотр: debounce выбора, отмена устаревшего запроса, scaled read, LRU-кэш с ключом из пути/времени/размера/версии декодера.
- Запуск из командной строки: `UniversalImageConverter.exe [файлы...] --format webp --quality 85 --output D:\out --start`,
  `--list-codecs` — вывести доступные форматы.

## Этап 5: форматы фото, метаданные, анимация

Окно «Поддерживаемые форматы…» (кнопка в строке состояния) и `UniversalImageConverter.exe --list-codecs`
показывают то, что **реально подтверждено при запуске**; формат без кодировщика в списке результата не предлагается.

| Формат | Чтение | Запись | Анимация / страницы | Метаданные (запись) | Библиотека |
|---|---|---|---|---|---|
| JPEG, PNG | да | да | — | да | Qt Image I/O |
| BMP | да | да | — | нет | Qt Image I/O |
| WEBP | да | да | чтение и запись всех кадров | да | Qt + libwebp (анимация) |
| GIF | да | да | чтение и запись всех кадров | нет | Qt (чтение) + giflib (запись) |
| TIFF | да | да | многостраничные: чтение и запись | да | Qt + libtiff (страницы) |
| HEIC/HEIF | да (HEVC) | **нет** (лицензия x265/GPL) | — | нет | libheif + libde265 |
| AVIF | да | да | — | нет | libheif + aom/dav1d |

- **Анимация** (политика в настройках): «все кадры» (по умолчанию, если формат результата это умеет),
  «только первый кадр» либо «отклонять». Если все кадры сохранить нельзя, это написано в предупреждениях до запуска.
  Задержки между кадрами и число повторов сохраняются. Проверка результата сверяет число кадров.
  GIF: общая палитра ≤256 цветов (медианное сечение, без дизеринга), прозрачность однобитная.
- **Метаданные EXIF/XMP/IPTC** (exiv2): «Удалить» / «Сохранить, кроме GPS» (по умолчанию) / «Сохранить всё, включая GPS».
  GPS переносится только по явному выбору. Ориентация в результате сбрасывается в 1 (она уже применена к пикселям),
  структурные теги исходного контейнера и встроенная миниатюра не копируются. Сбой переноса не уничтожает результат —
  он попадает в предупреждения.
- **HEIC/AVIF**: из файла берётся основное изображение (серии и Live Photo — первое изображение); трансформации контейнера
  (поворот/зеркало) применяет libheif, повторного поворота нет. Превью HEIC/AVIF декодирует файл целиком и уменьшает.
- Запись HEIC выключена: HEVC-кодировщик x265 распространяется под GPL. Включается сборкой `-DUIC_ENABLE_HEIC_ENCODE=ON`
  (тогда лицензия итоговой программы должна быть совместимой с GPL).

порт `IMetadataService` позволяет заменить exiv2 другой реализацией без правок остального кода.

## Архитектура

```
app/                  точка входа и корень композиции (выбор реализаций портов)
src/domain/           форматы, модели, состояния, Result — без Qt и Windows API
src/application/      сценарии: импорт, анализ, план, движок, очередь, превью; порты IImageDecoder/IImageEncoder
src/infrastructure/   qt_imageio (QImageReader/Writer), codecs (libheif, giflib, libwebp, libtiff),
                      metadata (exiv2), settings (QSettings)
src/ui/               Qt Widgets: MainWindow, FileListModel, DropArea
tests/                unit и integration (Qt Test)
```

Зависимости направлены к абстракциям: `ui → application → domain ← infrastructure`.
`uic_core` (domain + application + infrastructure) не зависит от Qt Widgets; GUI-поток не декодирует и не конвертирует.

| Класс | Роль |
|---|---|
| `FileImporter`, `FileValidator`, `FileAnalyzer`, `FormatDetector` | импорт, проверка пути, анализ, сигнатуры |
| `CodecRegistry` | реестр возможностей чтения/записи |
| `ConversionPlanner` | совместимость и предупреждения до запуска (анимация, метаданные, потери) |
| `CapabilityReport` | описание реально доступных возможностей для окна и CLI |
| `ConversionEngine` | decode → ImageBuffer → encode → проверка → фиксация |
| `QueueManager` | задачи, состояния, пулы потоков, отмена, повтор |
| `OutputNamer`, `AtomicFileWriter` | имена и атомарная запись |
| `PreviewController`, `ThumbnailGenerator`, `PreviewCache` | предпросмотр |
| `SettingsManager`, `CommandLineHandler` | настройки и аргументы запуска |

## Сборка (Windows, MSYS2 UCRT64)

```bash
pacman -S mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,qt6-base,qt6-imageformats,qt6-tools,libheif,exiv2,libtiff,giflib,libwebp,aom,libde265,dav1d}
export PATH=/c/msys64/ucrt64/bin:$PATH
cmake -S . -B C:/uic-build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build C:/uic-build
ctest --test-dir C:/uic-build --output-on-failure
```

Важно: **каталог сборки должен быть с ASCII-путём** (например `C:\uic-build`): `moc` Qt не создаёт файлы
в путях с кириллицей, как у папки «Курсовая работа».
Для запуска без MSYS2 соберите автономную папку: в оболочке MSYS2 UCRT64 выполните `scripts/deploy.sh /c/uic-build`
(windeployqt + все остальные DLL). После этого `UniversalImageConverter.exe` запускается двойным щелчком.

## Известные ограничения

- Метаданные не пишутся в BMP, GIF, HEIC и AVIF (приложение предупреждает до запуска); у HEIC/AVIF сведения о метаданных исходника тоже могут быть неполными.
- ICC сохраняется там, где формат его поддерживает; у исходников в быстром зондировании наличие ICC определяется не для всех форматов.
- Отмена срабатывает между этапами конвертации, а не посреди декодирования одного файла.
- Все кадры анимации держатся в памяти (лимит ≈1,5 ГиБ); для очень длинных анимаций выберите «только первый кадр».
- Анимированный HEIC/AVIF (последовательности изображений) не поддерживается.
- Не поддержаны: APNG, RAW, многослойные форматы.
